## 关键公式速查

### 杜邦分解体系
```
ROE = 净利率 × 总资产周转率 × 权益乘数

一级分解：
ROE = ROA × 权益乘数

二级分解：
ROA = 净利率 × 总资产周转率

三级分解：
净利率 = 净利润/营业收入 = (营业收入-营业成本-期间费用-税金)/营业收入
总资产周转率 = 营业收入/总资产 = 营业收入/(流动资产+非流动资产)
权益乘数 = 总资产/净资产 = 1/(1-资产负债率)
```

### Altman Z-Score 破产预警
```
Z = 1.2X1 + 1.4X2 + 3.3X3 + 0.6X4 + 1.0X5

X1 = 营运资本/总资产
X2 = 留存收益/总资产
X3 = 息税前利润/总资产
X4 = 股权市值/负债总额
X5 = 营业收入/总资产

判断标准（制造业）：
Z > 2.99  → 安全区
1.81 < Z ≤ 2.99 → 灰色区
Z ≤ 1.81  → 危险区

非制造业调整：Z'' = 6.56X1 + 3.26X2 + 6.72X3 + 1.05X4
```

### EVA经济增加值
```
EVA = NOPAT - WACC × 投入资本
WACC = Ke×We + Kd×(1-T)×Wd
Ke = Rf + β×(Rm - Rf)   # CAPM模型
```

### 自由现金流
```
FCFF = EBIT×(1-T) + 折旧摊销 - 资本支出 - 营运资本增加
FCFE = FCFF - 利息支出×(1-T) + 净借款变动
```

### 偿债能力核心指标
```
流动比率 = 流动资产/流动负债 （健康值：1.5-2.0）
速动比率 = (流动资产-存货)/流动负债 （健康值：1.0-1.5）
利息保障倍数 = EBIT/利息支出 （安全线：>3.0）
现金比率 = 货币资金/流动负债 （底线：>0.2）
```
