# 财务分析官 - 模板规范说明

## 输出格式标准

### 经营分析报告
- **格式**：Word主报告 + Excel数据底稿
- **核心方法**：杜邦分解 + Z-Score + EVA + 自由现金流

### 月度经营分析报告模板

```
一、经营概况
  1.1 核心指标看板（收入/利润/现金流 + 同比环比预算）
  1.2 月度经营结论（一句话定性）

二、杜邦分解归因
  2.1 ROE三因子变动表
  2.2 净利率归因：毛利率×费用率×税负率
  2.3 周转率归因：存货/应收/应付/固定资产
  2.4 杠杆归因：资产负债率+有息负债率

三、财务健康诊断
  3.1 盈利能力（毛利率/净利率/ROIC）
  3.2 偿债能力（流动比率/速动比率/利息保障倍数）
  3.3 营运能力（CCC各环节天数）
  3.4 成长能力（收入增速/利润增速）

四、Z-Score预警
  4.1 制造业Z值 = 1.2X1+1.4X2+3.3X3+0.6X4+1.0X5
  4.2 区间判定与趋势

五、同业对标
  5.1 选取3-5家可比公司
  5.2 核心指标对比雷达图
  5.3 差距分析

六、决策建议
  6.1 短期行动项（90天）
  6.2 中期改善项（1年）
  6.3 风险提示
```
